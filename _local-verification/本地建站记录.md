## 安装时踩到的 3 个坑（及处理）
1. **`package.json` 里有 `"ryze": "link:"` 自引用**（作者本地残留，npm 直接报 Unsupported URL Type）。
   → 这是唯一必须动的依赖项；pnpm 能识别 `link:`，按 lock 安装时保留原样即可。
2. **不能用 `npm install` 装这个模板**：`^` 范围会解析到 astro 6.4.8 + vite 8.3.0（rolldown 内核），
   而 `@tailwindcss/vite` 需要 `BindingViteResolvePluginConfig.resolveOptions.tsconfigPaths`
   这个 vite 8 已移除的字段 → 构建报错
   `[@tailwindcss/vite:generate:build] Missing field 'tsconfigPaths'`。
   → 必须用 pnpm 按 lock 安装（astro 6.1.3 配 vite 7.3.1）。
3. **pnpm 12 默认拦截依赖构建脚本**（ERR_PNPM_IGNORED_BUILDS：esbuild / sharp / msw）。
   → 本机实测未批准也能正常构建（esbuild 用的是 `@esbuild/win32-x64` 预编译包，sharp 0.34 用 `@img/sharp-win32-x64`），
   如需消除该报错：`pnpm approve-builds` 或 `pnpm config set only-built-dependencies[] esbuild`。

## 与线上的 3 处非功能性差异
1. `astro-island uid/hash`：每次构建随机生成（水合标识），不影响呈现。
2. `<meta name="google-site-verification">` 本地为空 —— 模板读 `import.meta.env.PUBLIC_GOOGLE_SITE_VERIFICATION`，
   仓库 `.env` 被 gitignore，线上是 Cloudflare 构建时注入的。
   要补：在项目根建 `.env` 写 `PUBLIC_GOOGLE_SITE_VERIFICATION=<Google 给的串>`。
3. RSS `pubDate` 时区差：文中日期 `"30-05-2026"` 按本地 0 点解析，本机 UTC+8 得到 `Fri, 29 May 2026 16:00:00 GMT`，
   线上 CI（UTC）是 `Sat, 30 May 2026 00:00:00 GMT`。日期语义相同，只是时区记账。
   要完全一致：构建时 `set TZ=UTC`。

## 运维注意（踩过的坑）
- **在对话里跑的后台构建会被会话结束回收**：`npm run build` 中途被杀 → `dist/` 被清空，
  此时 `astro preview` 进程还活着但对所有路由返回 **404**（服务在、内容没了）。
  遇到「全站 404」先看 `dist/` 是否为空，重跑构建即可，不要怀疑路由配置。
- `astro preview` 端口被占会**自动跳到下一个端口**（日志里 `Local http://localhost:4324/`），
  脚本/验证要对准真实端口；`astro dev`/`preview` 被 kill 包装进程后子进程可能变孤儿，按 PID 清。
- 验证完的临时端口（4322/4323/4324）已全部关闭，仅保留 4321 预览。
